--------------------------------------------------------------------------------
1. OBIETTIVI E SPECIFICHE CHIAVE
--------------------------------------------------------------------------------
- Scopo: Guida, imposizione e blocco totale di contenuti NSFW su Android e rete locale per la sfida NNN (No Nut November o durata personalizzata).
- Design System: Material Design 3 Dark Theme con accenti Viola Elettrico (#7C3AED, #A855F7, #C084FC), sfondo Nero OLED (#0B0813, #120E1E), ed effetti "Bloom" (glow/bagliori al neon dinamici) su pulsanti, anello di progresso, badge e stato di allerta.
- App Nativa: Struttura ibrida nativa Android (Capacitor Android wrapper) che produce un progetto Android nativo con supporto ad API di sistema (DeviceAdmin, notifiche, secure storage, intents).
- Anti-Bypass & Lockdown Irreversibile: Meccanismo di impegno ("No Turning Back"). Una volta avviata la sfida, non è possibile tornare indietro.
- Cassaforte Password a Tempo (Time-Lock Vault): Memorizza la password del Pi-hole o del router; la password viene cifrata e tenuta nascosta, sbloccandosi SOLO al termine del periodo stabilito.
- Controllo Integrità Giornaliero & Penalità: Check automatico periodico della risoluzione DNS protetta. Se viene rilevato un tentativo di disattivazione o cheat, scatta una penalità (es. estensione del timer di blocco o penalità di streak).
- Integrazione Pi-hole v6: Supporto bidirezionale:
    a) Connessione diretta via REST API Pi-hole v6 (IP + API Key per blocco automatico, inserimento adlists e cambio/lockdown password).
    b) Generatore di liste manuale (URL Adlists NSFW curati e configurazioni CNAME SafeSearch da incollare nell'interfaccia web).
- Panic Button a 3 vie: Intervento rapido anti-ricaduta senza possibilità di disattivare il blocco (Respirazione guidata con cerchio bloom, Timer doccia fredda / contatore flessioni, Feed motivazionale anti-relapse).
- Blocker Tester: Diagnostica live per verificare se i DNS anti-NSFW e SafeSearch sono attivi.
- Diario Cifrato: Note giornaliere cifrate localmente con AES-GCM.

3. DETTAGLIO FUNZIONALITÀ E LOGICA DI SISTEMA
--------------------------------------------------------------------------------

3.1. Design System & Bloom Effects
- Colori:
  - Background: #0B0813 (OLED Black profondo)
  - Surface: #120E1E (Dark Violet Container)
  - Surface High: #1A1429
  - Primary: #A855F7 (Electric Purple)
  - Primary Container: #3B185F
  - Tertiary / Accent: #EC4899 (Neon Magenta)
  - Error / Warning: #EF4444 (Crimson Alert)
- Effetti Bloom:
  - Ombre multi-layer sfumate con filtri CSS drop-shadow e box-shadow su toni rgba(168, 85, 247, 0.45).
  - Respiratore con cerchio a gradiente radiale pulsante ed effetto aura luminescente.
  - Indicatore di Streak con anello SVG circolare e luce bloom al completamento.

3.2. Integrazione Pi-hole v6 (Dual Mode)
- Modalità API Pi-hole v6:
  - Endpoint v6: POST /api/auth (login con password/app password).
  - Endpoint v6: GET/POST /api/lists (iniezione automatica delle liste NSFW con tag "NNN_SHIELD").
  - Endpoint v6: POST /api/dns/blocking (verifica o forzatura blocco attivo).
  - Lockdown Password Pi-hole: Generazione password casuale sicura a 32 caratteri, aggiornamento su Pi-hole via API e salvataggio cifrato nella Cassaforte Temporale.
- Modalità Manuale:
  - Selettore con copy-to-clipboard a 1-tap per le migliori liste (StevenBlack Porn, OISD NSFW, HaGeZi Pro++ Porn).
  - Istruzioni per forzare SafeSearch tramite record DNS locali in Pi-hole (forcesafesearch.google.com).

3.3. Android Anti-Bypass & Hardcore Lockdown
- Configurazione DNS Privato (DoT):
  - Setup guidato su CleanBrowsing Adult (adult-filter-dns.cleanbrowsing.org) o Cloudflare Family (family.cloudflare-dns.com) o AdGuard Adult.
  - Tasto rapido con Intent Android per aprire direttamente le impostazioni di Rete/DNS Privato.
- Protezione contro la disattivazione facile:
  - Guida alla configurazione di "VPN Always-on" con blocco del traffico senza VPN, oppure blocco delle impostazioni tramite Parental/Digital Wellbeing PIN gestito da terzi o tramite Cassaforte.
  - Attivazione del Device Admin / Accessibility Warning: l'app registra lo stato e monitora se il DNS viene rimosso.
- No Turning Back:
  - Modale di conferma ad alto impatto prima di sigillare la sfida.
  - Se l'app viene disinstallata o i dati cancellati, la chiave AES-GCM viene distrutta e la password del vault va persa fino al reset manuale del router/Pi-hole.

3.4. Time-Lock Password Vault & Integrity Check
- Crittografia:
  - Utilizzo di Web Crypto API nativa (SubtleCrypto: PBKDF2 + AES-GCM 256-bit).
  - La chiave è associata a un timestamp di sblocco in millisecondi (targetDate).
  - L'algoritmo rifiuta la decifratura se il timestamp corrente è inferiore alla data di sblocco stabilita.
- Anti-Cheat & Penalità:
  - Canary DNS Check: l'app tenta di risolvere saltuariamente un endpoint canary filtrato. Se la risposta non è bloccata, registra una violazione.
  - Sistema a penalità: ogni violazione aggiunge +24 ore di blocco al vault e segnala uno "Strike" sulla streak.

3.5. NNN Companion Suite
- Streak Tracker:
  - Durata flessibile (30 giorni standard o range libero).
  - Check-in giornaliero con motivazione e tracciamento percentuale.
  - Sistema di trofei: Day 1 (Inizio), Day 3 (Resistenza), Day 7 (1 Settimana), Day 14 (Metà strada), Day 21 (Abitudine d'Acciaio), Day 30 (Trascendenza).
- Panic Button a 3 Vie:
  - Accesso istantaneo dalla bottom bar.
  - 1. Box Breathing / 4-7-8 con guida ritmica visiva bloom e vibrazione tattile (Haptic feedback).
  - 2. Quick Physical Reset: timer per doccia fredda o contatore flessioni per rilasciare dopamina/endorfine fisiche.
  - 3. Anti-relapse Quotes: feed motivazionale e verità scientifiche sul reset recettoriale della dopamina.
- Blocker Diagnostic Tester:
  - Verifica in tempo reale di connettività, DNS filtering e stato SafeSearch con badge visivo (Protetto / Rischio).
- Diario Personale Cifrato:
  - Note giornaliere su umore, trigger incontrati ed energia.
  - Testo salvato in forma cifrata nel database locale IndexedDB.
